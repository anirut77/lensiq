# LENSIQ — Computer Vision เพื่อการตลาดและการวิเคราะห์ ที่ทำงานบนเครื่องของคุณ

**เปลี่ยนกล้องที่มีอยู่ให้เป็นข้อมูลการตลาด — ไม่ส่งภาพขึ้นคลาวด์ ไม่บันทึกวิดีโอ ออกแบบตาม PDPA**

## ปัญหาที่แก้

- ร้านค้าและบูธไม่รู้ว่า "มีคนเข้ากี่คน ช่วงไหนคนเยอะ ยืนดูตรงไหนนาน" จึงจัดคนและโปรโมชันจากความรู้สึก
- ระบบกล้องอัจฉริยะทั่วไปส่งภาพขึ้นคลาวด์ ค่าบริการรายเดือนสูง และเสี่ยงต่อข้อมูลส่วนบุคคล
- ป้ายโฆษณา/ตู้ถ่ายรูปไม่มีตัวชี้วัดว่าคุ้มค่าหรือไม่

## สิ่งที่ LENSIQ ทำ

| กลุ่ม | ระบบ | ผลลัพธ์ |
|---|---|---|
| วิเคราะห์หน้าร้าน | นับคนเข้า–ออก, แผนที่ความร้อน, คิว, หลายกล้อง/หลายสาขา | รายงานรายชั่วโมง เปรียบเทียบช่วงเวลา พร้อมช่วงความเชื่อมั่น |
| การตลาด | ป้ายโฆษณาอัจฉริยะ, วิเคราะห์บูธ, ทดสอบโฆษณาจากสีหน้า, จดจำสมาชิก (สมัครใจ) | เวลาดูโฆษณา ผู้เข้าชมไม่ซ้ำ ความสนใจ |
| ตู้ถ่ายรูปและสตูดิโอ | ตัดพื้นหลัง รูปติดบัตร สตูดิโอแต่งชุด | สร้างการมีส่วนร่วมในงาน/หน้าร้าน |
| ดูดวงเพื่อความบันเทิง | 11 ศาสตร์ (ลายมือ โหงวเฮ้ง ไพ่ทาโรต์ ฮวงจุ้ย เลขมงคล ฯลฯ) | ดึงคนเข้าบูธ แชร์การ์ดผลลัพธ์ |
| ระบบเสริม | สแกนสินค้า, ตรวจคุณภาพ, เช็กชื่อด้วยใบหน้า, เตือนง่วงคนขับ, แปลง PDF | งานหลังร้านด้วยกล้องตัวเดียว |

## ทำไมต้อง LENSIQ

- **ประมวลผลบนเครื่อง 100%** — เปิดในเบราว์เซอร์ ใช้ได้แม้ออฟไลน์ ไม่มีค่าคลาวด์ต่อกล้อง
- **ความเป็นส่วนตัวเป็นค่าเริ่มต้น** — ไม่เก็บภาพ, ค่าใบหน้าเข้ารหัส AES-256, ไม่มีการส่งข้อมูลให้บุคคลที่สาม (ฟอนต์และไลบรารีทั้งหมดอยู่ในระบบ)
- **พร้อมเอกสาร PDPA** — DPIA ฉบับกรอกแล้ว, ROPA, ข้อความแจ้ง/ขอความยินยอม, ตารางระยะเวลาเก็บ (ต้องให้ฝ่ายกฎหมายตรวจทาน)
- **ใช้กล้องที่มีอยู่** — เว็บแคม มือถือ แท็บเล็ต; มือถือหลายเครื่องรวมยอดเข้าเครื่องหลักผ่าน Wi-Fi ร้าน (ส่งเฉพาะตัวเลข)
- **ตัวเลขโปร่งใส** — เผยผลวัดความแม่นยำจริงบนชุดข้อมูลสาธารณะ (`ACCURACY.md`) และมีแผนทดลองหน้าร้านพร้อมเกณฑ์ยอมรับก่อนใช้งานจริง
- **ไทยและจีน** — สลับ TH | 中文 ได้ทุกหน้า
- **สัญญาอนุญาตพร้อมใช้เชิงพาณิชย์ในค่าเริ่มต้น** — ส่วนที่ห้ามใช้เชิงพาณิชย์ปิดไว้และต้องยืนยันสิทธิ์ก่อนเปิด

## เริ่มใช้งานใน 3 ขั้นตอน

1. **สำรวจหน้างาน** — ตำแหน่งกล้อง แสง เครือข่าย (1 วัน)
2. **ทดลอง 4 สัปดาห์** — ติดตั้ง วัดเทียบกับการนับด้วยคน ตามเกณฑ์ใน `docs/PILOT-PLAN.md` (เช่น ยอดรายวันคลาดเคลื่อน ≤ 5%)
3. **ใช้งานจริง + ดูแล** — แพ็กเกจบริการ Basic / Standard / Premium ตาม `docs/SUPPORT.md`

## ข้อจำกัดที่บอกตรง ๆ

- ความแม่นยำขึ้นกับมุมกล้องและแสง — คนตัวเล็ก/ไกลมาก หรือฝูงชนหนาแน่น นับได้ต่ำกว่าจริง จึงต้องทดลองหน้าร้านก่อน
- การประเมินอายุ/เพศ/อารมณ์เป็นค่าประมาณ ใช้ดูภาพรวม ไม่ใช้ตัดสินรายบุคคล
- ดูดวงเพื่อความบันเทิงเท่านั้น
