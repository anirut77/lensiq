# LENSIQ สำหรับร้านค้าปลีก — รู้ว่าลูกค้าเข้าร้านกี่คน ช่วงไหน ยืนดูตรงไหน โดยไม่เก็บภาพ

**ใช้กล้องที่มีอยู่ ประมวลผลบนเครื่องในร้าน ไม่ส่งภาพขึ้นคลาวด์ ไม่บันทึกวิดีโอ**

## ปัญหาของร้าน
- จัดพนักงานและโปรโมชันจากความรู้สึก เพราะไม่รู้จำนวนคนเข้าร้านจริงรายชั่วโมง
- ไม่รู้ว่าป้ายหน้าร้าน ชั้นวาง หรือจอโฆษณาทำให้คนหยุดดูหรือไม่
- ระบบกล้องอัจฉริยะทั่วไปส่งภาพขึ้นคลาวด์ มีค่ารายเดือนต่อกล้อง และเสี่ยงเรื่อง PDPA

## สิ่งที่ได้
| ระบบ | ผลลัพธ์ |
|---|---|
| วิเคราะห์หน้าร้าน | นับคนเข้า–ออก แผนที่ความร้อน ความยาวคิว หลายกล้อง/หลายสาขารวมยอดผ่าน Wi-Fi ร้าน (ส่งเฉพาะตัวเลข) |
| แดชบอร์ดรวม | สรุปรายวัน/สัปดาห์ เทียบช่วงเวลา พร้อมช่วงความเชื่อมั่น และป้าย “ข้อมูลยังไม่พอ” เมื่อตัวอย่างน้อย |
| ป้ายโฆษณาดิจิทัล | เวลาดู อัตรามอง เลือกคอนเทนต์ตามผู้ชม (ค่าประมาณอายุ/เพศปิดเป็นค่าเริ่มต้น) |
| Creative Lab | ตรวจชิ้นงานก่อนพิมพ์: แผนที่ความสนใจ ความคมชัด สี เทียบ A/B |
| จดจำสมาชิก (สมัครใจ) | จำลูกค้าประจำด้วยใบหน้าเฉพาะผู้ยินยอม เข้ารหัสในเครื่อง มีทางเลือกค้นด้วยเบอร์โทร |
| สแกนสินค้าด้วยกล้อง | คิดเงินแบบบริการตนเอง สต็อก และรายงานยอดขาย |

## ทำไมเชื่อถือได้
- **ตัวเลขโปร่งใส:** ผลวัดบนชุดข้อมูลสาธารณะเผยแพร่พร้อมข้อจำกัด (`ACCURACY.md`) และ **ทดลองหน้าร้าน 2 สัปดาห์** เทียบกับการนับด้วยคน เกณฑ์ยอมรับ เช่น ยอดรายวันคลาดเคลื่อน ≤ 5% (`docs/PILOT-PLAN.md`)
- **PDPA ตั้งแต่ต้น:** ป้ายแจ้งการใช้กล้องพิมพ์ได้ 3 ภาษา แม่แบบ DPIA/ROPA ข้อความขอความยินยอม (ต้องให้ฝ่ายกฎหมายของร้านตรวจทาน)
- **ไม่มีค่าคลาวด์ต่อกล้อง** เปิดในเบราว์เซอร์ ใช้ได้แม้ออฟไลน์

## แพ็กเกจ
| ระดับ | เหมาะกับ |
|---|---|
| ผู้เยี่ยมชม / สมาชิก (ฟรี) | ทดลองเองทุกระบบบนเครื่อง |
| Business | 1–20 จุด รวมยอดหลายสาขา ส่งออก CSV ตอบกลับวันทำการถัดไป |
| องค์กร | ติดตั้งในเครือข่ายภายใน DPA ตามมาตรา 40 SLA ตามสัญญา |

ราคาเป็นฉบับร่างจนกว่าจะเปิดขาย — ยืนยันในใบเสนอราคา

**ขั้นตอนถัดไป:** สำรวจหน้างาน 1 วัน → ทดลอง 2 สัปดาห์ → รายงานผลที่ลงนามร่วมกัน
