## 2. การติดตั้งกล้องสูง ≥ 2.6 เมตร

| ☐ | รายการ | รายละเอียด |
|---|---|---|
| ☐ | ขาตั้งไฟสตูดิโอ (light stand) สูง ≥ 2.8 ม. + หัวบอลพร้อมเกลียว 1/4 นิ้ว | 1 ต้นต่อ 1 ตำแหน่งกล้อง · ถ่วงฐานด้วยถุงทรายหรือขวดน้ำ ≥ 5 กก. · ติดเทปกันสะดุดรอบฐาน |
| ☐ | ทางเลือกแทนขาตั้ง | แคลมป์ยึดกับรางม่าน คานฝ้า หรือขอบกระดาน · ฉากยึดติดผนังด้วยเทปกาวสองหน้าแบบลอกได้ (ขออนุญาตเจ้าของห้องก่อน) · ไม้ต่อ (monopod / ไม้เซลฟี่แบบแข็ง) รัดกับชั้นหรือตู้สูงด้วยสายรัด · ขาตั้งไมโครโฟนแบบบูมต่อความสูง |
| ☐ | ตลับเมตร หรือเครื่องวัดระยะเลเซอร์ | วัดความสูงเลนส์จากพื้น ระยะถึงแถวหน้าสุดและแถวหลังสุด ขนาดห้อง ระยะห่างแถว |
| ☐ | บันไดหรือเก้าอี้ที่มั่นคง | ใช้ตอนติดตั้งเท่านั้น มีคนจับ |
| ☐ | เทปทำเครื่องหมายตำแหน่งขาตั้งบนพื้น | ถ้าขาตั้งถูกชน จะวางคืนที่เดิมได้ และใช้ในการทดสอบ "ขยับกล้อง" ท้ายรอบ |
| ☐ | สายรัดเคเบิลไทร์ / เทปผ้า | รัดสาย USB กับขาตั้ง ไม่ให้น้ำหนักสายดึงกล้อง |

ตำแหน่งที่ทดสอบ: (1) ผนังหน้าห้อง กึ่งกลาง หันหาผู้สอบ (2) มุมห้องสูงสองมุมตรงข้ามกัน (3) ถ้ามีเครื่องเหลือ: ผนังหลังห้อง
ทุกตำแหน่งเลนส์สูง ≥ 2.6 ม. ก้มลงให้เห็นแถวหน้าสุดถึงแถวหลังสุดในภาพเดียว
