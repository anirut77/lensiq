# แผ่นบันทึกของผู้สังเกต (คนที่สอง) — การสอบจำลอง LENSIQ Exam "เฝ้าที่นั่ง"

> ฉบับร่าง 10 พ.ย. 2569 · ใช้คู่กับ `PILOT-HALL-SEATWATCH.md` (ข้อ 4, 5, 13) และไฟล์ `label-sheet-template.csv`
> แผ่นนี้คือ "คำตอบที่ถูก" ของการวัดผล ตัวเลขทั้งหมดขึ้นกับความแม่นของแผ่นนี้

## 1. หน้าที่ของท่าน

ท่านจด**สิ่งที่เกิดขึ้นจริงในห้อง** ว่าเกิดที่ที่นั่งใด เริ่มและจบเมื่อใด เพื่อนำไปเทียบกับสิ่งที่ระบบแจ้งภายหลัง

- จดเฉพาะ**ข้อเท็จจริงที่มองเห็น** เช่น "B3 ลุกออกจากที่นั่ง 10:04:10 กลับ 10:05:20" **ห้ามจดความเห็น** เช่น "ดูมีพิรุธ" "น่าสงสัย" "ตั้งใจ"
- **ไม่จดชื่อคน** ใช้หมายเลขที่นั่งเท่านั้น
- **ห้ามดูหน้าจอคอมพิวเตอร์ของระบบ แดชบอร์ด หรือฟังเสียงเตือน** และห้ามคุยเรื่องการแจ้งเตือนกับผู้ควบคุมเครื่องจนกว่าจะส่งแผ่นแล้ว
  (ถ้าท่านรู้ว่าระบบแจ้งอะไร แผ่นนี้จะใช้ไม่ได้)
- ถ้าไม่แน่ใจ ให้จดตามที่เห็นและเขียน "ไม่แน่ใจ" ในหมายเหตุ อย่าเดา อย่าแก้ย้อนหลังหลังจากรู้ผลของระบบ

## 2. ก่อนเริ่ม

1. นั่งในจุดที่เห็น**ทุกที่นั่งและนาฬิกากลางห้อง** แต่ไม่เห็นหน้าจอใด ๆ
2. รับแผ่นที่พิมพ์จากตารางบทของช่วงนั้น (มีเหตุการณ์ตามบทเรียงตามเวลาอยู่แล้ว) และแผ่นเปล่าสำหรับเหตุการณ์นอกบท
3. ดูผังห้อง: หมายเลขที่นั่ง (แถว A อยู่หน้าสุด) เส้นเทปแบ่งเขตที่นั่ง จุด X ในทางเดิน
4. เวลาทุกช่องใช้**นาฬิกากลางห้อง**เรือนเดียว ซึ่งเป็นตัวจับเวลานับขึ้นจาก 00:00 เมื่อเริ่มแต่ละช่วง เขียนเป็น นาที:วินาที
   (รอบ 3 ชั่วโมง: ชั่วโมง:นาที:วินาที) อย่าใช้นาฬิกาข้อมือหรือโทรศัพท์ของตัวเอง
5. เขียนหัวแผ่น: รหัสรอบ ช่วง (D1, H1 …) วันที่ ชื่อย่อของท่าน

## 3. ชนิดเหตุการณ์ (ใช้รหัสตามนี้เท่านั้น)

| รหัส | เกิดอะไรขึ้น | เริ่มนับเมื่อ | จบเมื่อ |
|---|---|---|---|
| `LEAVE` | ลุกออกจากที่นั่ง (รวมเข้าห้องน้ำจริง) | ตัวออกพ้นเส้นเทปของที่นั่งตัวเอง | กลับมานั่งบนเก้าอี้แล้ว |
| `AISLE` | มีคนยืนหรือเดินอยู่นอกเขตที่นั่งทุกเขต (ในทางเดิน หน้าห้อง หลังห้อง) | คนแรกออกมาอยู่นอกเขตที่นั่ง | ไม่มีใครอยู่นอกเขตที่นั่งแล้ว |
| `SECOND` | มีคนที่สองยืนหรือย่อตัวอยู่ในเขตที่นั่งของคนอื่นที่นั่งอยู่ | คนที่สองเข้ามาในเส้นเทปของที่นั่งนั้น | คนที่สองออกไป |
| `LEAN` | คนที่นั่งอยู่เอนตัวจนไหล่ข้ามเส้นเทปไปทางที่นั่งข้าง ๆ ในแถวเดียวกัน | ไหล่ข้ามเส้น | ไหล่กลับเข้าเขตตัวเอง |
| `STAND` | ยืนตรงที่ที่นั่งตัวเอง เท้ายังอยู่ในเขต | ยืนเต็มตัว | นั่งลง |
| `PHONE_DESK` | โทรศัพท์วางบนโต๊ะ หงายจอ (เฉพาะช่วงเสริม P) | วางลง | เก็บ |
| `PHONE_HAND` | ถือโทรศัพท์เหนือระดับโต๊ะ (เฉพาะช่วงเสริม P) | ยกขึ้น | เก็บ |
| `STAFF_WALK` | ผู้คุมสอบเดินในห้อง (จดในช่อง walk_mode ว่า on หรือ off ตามที่ตารางบทระบุ) | เริ่มเดิน | กลับถึงที่ |
| `DISTRACT` | ยืดตัว ก้มเก็บของ ถอด/ใส่เสื้อ แขวนกระเป๋า ฟุบหน้า หันหลัง (เขียนว่าอะไรในหมายเหตุ) | เริ่มทำ | เลิกทำ |
| `CAM_MOVED` | มีคนแตะ ชน หรือขยับกล้องหรือขาตั้ง | เวลาที่เห็น | – |
| `OTHER` | อย่างอื่นที่อาจเกี่ยว เช่น เปิดประตู เปิด/ปิดไฟ มีคนนอกเข้ามา ของตกเสียงดัง | เริ่ม | จบ |

## 4. วิธีกรอกแต่ละแถว

| ช่อง | กรอกอะไร |
|---|---|
| `source` | `scripted` = มีในตารางบท (พิมพ์มาแล้ว) · `unscripted` = เกิดเองนอกบท (ท่านเพิ่มเอง) |
| `planned_time` | เวลาตามบท (พิมพ์มาแล้ว) |
| `event_type` | รหัสจากตารางข้อ 3 |
| `seat` | ที่นั่งของคนที่ทำ (`AISLE` นอกบท: ที่นั่งของคนนั้นถ้ารู้ ไม่รู้ให้เว้น · ผู้คุมสอบ: `STAFF`) |
| `target_seat` | `SECOND`: ที่นั่งที่ถูกไปยืนข้าง · `LEAN`: ที่นั่งข้างที่เอนไปหา |
| `on_time` | `Y` = เริ่มตรงเวลาตามบท คลาดไม่เกิน 3 วินาที และนานตามบท · `N` = คลาดหรือสั้น/ยาวกว่าบท → ต้องกรอกเวลาจริง · `X` = ไม่ได้ทำ (ขีดฆ่าแถว) |
| `actual_start` / `actual_end` | เวลาจริงจากนาฬิกากลางห้อง **ต้องกรอกเสมอ**เมื่อ `on_time` = N และทุกแถว `unscripted` · `LEAVE` ต้องกรอก `actual_end` (เวลากลับมานั่ง) ทุกครั้ง |
| `walk_mode` | เฉพาะ `STAFF_WALK`: on / off |
| `object_on_chair` | เฉพาะ `LEAVE`: `Y` ถ้ามีกระเป๋าหรือเสื้อวางอยู่บนเก้าอี้ระหว่างที่ไม่อยู่ |
| `note` | ข้อเท็จจริงสั้น ๆ เช่น "คนแถวหน้าบัง" "ยืนคร่อมเส้นเทป" "ไม่แน่ใจเวลาเริ่ม" |
| `labeller` | ชื่อย่อของท่าน |

ลำดับความสำคัญเมื่อหลายอย่างเกิดพร้อมกัน: (1) เหตุการณ์นอกบท (2) `LEAVE` และเวลากลับ (3) `SECOND` (4) `AISLE` (5) `LEAN` (6) ที่เหลือ
เหตุการณ์ตามบทที่ท่านไม่ทันดู ให้เขียน "ไม่ได้ดู" ในหมายเหตุ **อย่าติ๊ก Y ถ้าไม่ได้เห็นเอง**

## 6. หลังจบแต่ละช่วง

1. ตรวจว่าทุกแถว `LEAVE` มีเวลากลับ และทุกแถว N / unscripted มีเวลาเริ่มและจบ
2. เซ็นชื่อย่อและเวลาที่ส่ง แล้ว**ส่งแผ่นให้ผู้ควบคุมเครื่องก่อน**จะได้เห็นผลของระบบ หลังส่งแล้วห้ามแก้แผ่น (แก้ได้เฉพาะในขั้นตอนข้อ 7 โดยเขียนกำกับ)
3. ผู้ควบคุมเครื่องพิมพ์ข้อมูลลง `label-sheet-template.csv` (หนึ่งแถวต่อหนึ่งเหตุการณ์ ลบแถวตัวอย่างออก) และเก็บแผ่นกระดาษไว้เป็นหลักฐาน

## 7. เมื่อแผ่นกับระบบไม่ตรงกัน

ทำหลังส่งแผ่นแล้วเท่านั้น ตามลำดับนี้ (กำหนดไว้ล่วงหน้า ห้ามเปลี่ยนหลังเห็นผล):

1. ผู้ควบคุมเครื่องทำรายการ (ก) การแจ้งเตือนที่ไม่มีแถวในแผ่นรองรับ และ (ข) แถวในแผ่นที่ระบบไม่ได้แจ้ง
2. ผู้สังเกตและผู้ควบคุมเครื่องดูรายการทีละข้อ เทียบกับตารางบทที่พิมพ์ไว้และหมายเหตุในแผ่น
   **ข้อเท็จจริงที่ผู้สังเกตจดไว้ถือเป็นหลัก ระบบไม่ใช่หลักฐานว่าเหตุการณ์เกิดขึ้น**
3. ถ้ามีวิดีโอที่ทุกคนยินยอม (ใบยินยอมแบบ ข.) ให้เปิดดูเฉพาะนาทีนั้นด้วยกัน แล้วผู้สังเกตเป็นผู้ตัดสิน
4. ถ้ายังสรุปไม่ได้ ให้ลง "ไม่แน่ใจ" รายงานจะแสดงข้อนี้แยก และนับเป็น "แจ้งผิด" ในบรรทัดกรณีเลวร้ายที่สุด
5. ถ้าไม่มีวิดีโอ เหตุการณ์จริงที่ผู้สังเกตไม่ได้เห็นจะถูกนับเป็นการแจ้งผิดของระบบ (ตั้งใจให้เข้มกับระบบ)
6. ทุกการแก้แผ่นในขั้นนี้ ให้เขียนเพิ่มด้วยปากกาสีอื่น ลงชื่อย่อสองคน และไม่ลบของเดิม

ถ้ามีผู้สังเกตสองคน: ช่วงซ้อมช่วงแรก (D1) ให้จดทั้งห้องทั้งสองคนโดยไม่ดูแผ่นของกัน แล้วเทียบกัน (เหตุการณ์เดียวกัน เวลาเริ่มต่างไม่เกิน 5 วินาที = ตรงกัน)
รายงานสัดส่วนที่ตรงกัน และตกลงข้อที่ต่างกันให้เสร็จก่อนเริ่มช่วงตัดสิน (H1)
