# ภาษาไทย

## 1. ขนาดของการนำร่องที่รายการนี้รองรับ

นำร่อง "วันเดียวในห้องคอมพิวเตอร์ของสถาบัน" ตาม `docs/pilot/PILOT-EXAM.md` ขั้น 0 (ตรวจกล้องและแสง) และขั้น 1 (สอบจำลองตามบท):
อาสาสมัครผู้ใหญ่ **≥ 10 คน** (เกณฑ์ขั้นต่ำของขั้น 0) นั่งเครื่องคอมพิวเตอร์ของห้องคนละ 1 เครื่อง ใช้ `exam-lab.html`
ตัวเลขจำนวนด้านล่างคำนวณจากขนาดนี้ ถ้าจำนวนอาสาสมัครต่างไป ให้ปรับตามส่วนที่ระบุว่า "ตามจำนวนอาสาสมัคร"
ขั้น 2 (สอบจริง ห้องละ 20–40 คน อย่างน้อย 3 ห้อง) ใช้รายการเดียวกันซ้ำต่อห้อง ยกเว้นส่วนที่ทำเครื่องหมายว่าเฉพาะขั้น 0–1

**โหมด B (ตัวหลักของการนำร่อง):** แต่ละเครื่องผู้สอบประมวลผลและเก็บบันทึกของตัวเอง ไม่มีภาพหรือวิดีโอออกจากเครื่อง
**ยังไม่ส่งสด** ไปแดชบอร์ดเครื่องอื่น (ข้อจำกัดที่เจ้าของยอมรับ 10 พ.ย. 2569, `docs/pilot/PILOT-EXAM.md` §2) จึงต้องมีวิธีขนไฟล์ JSON จากแต่ละเครื่องไปแดชบอร์ดหลังสอบ

สถานะราคาในตาราง: **0** = มีอยู่แล้วหรือยืมได้ · **ไม่ทราบ** = ต้องเช็คราคาจริงก่อนตัดสินใจ · **ประมาณการ** = ตัวเลขกว้าง ๆ ของผู้ร่าง ไม่ได้ตรวจราคา

# English

## 1. Size of the pilot this list supports

A one-day pilot in the institute's computer lab covering `docs/pilot/PILOT-EXAM.md` phase 0 (camera and light check) and phase 1 (staged exam): **at least 10 adult volunteers**
(the phase-0 minimum), one lab PC each, running `exam-lab.html`. Quantities below follow from that size; scale the lines marked "per volunteer". Phase 2 (real exam, 20–40 per room, at least 3 rooms) repeats this list per room.

**Mode B:** each candidate PC processes and keeps its own log; no image or video leaves the PC. There is **no live feed** to a dashboard on another machine
(limit accepted by the owner on 2026-11-10, `docs/pilot/PILOT-EXAM.md` §2), so you need a way to carry each PC's JSON file to the dashboard after the session.
