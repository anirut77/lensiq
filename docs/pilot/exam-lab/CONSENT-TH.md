## 1. เราขอให้ท่านทำอะไร

- นั่งที่เครื่องคอมพิวเตอร์ของห้องเหมือนกำลังสอบ เปิดหน้า LENSIQ Exam และใช้ช่อง "พื้นที่ทำข้อสอบ" ทำแบบฝึกหัดตามที่ผู้จัดให้ **ไม่มีการตรวจหรือให้คะแนนแบบฝึกหัด**
- ทำตาม "บัตรคิว" ในเวลาที่กำหนดโดยนาฬิกากลางห้อง เช่น หันหน้าออกจากกล้อง ถือโทรศัพท์ให้กล้องเห็น ออกจากเต็มจอ สลับแท็บ วางข้อความ ลุกออกจากที่นั่ง
  ทุกอย่างเป็น**การแสดงตามบท** เพื่อให้เรารู้เวลาที่เกิดจริง ไม่ใช่การทดสอบตัวท่าน
- ใช้เวลาประมาณ [จำนวน] ชั่วโมง มีช่วงพัก [จำนวน] ครั้ง ท่านลุกไปห้องน้ำหรือดื่มน้ำได้ทุกเมื่อโดยไม่ต้องขออนุญาต
- [ถ้ามี: ค่าตอบแทน / อาหาร / ค่าเดินทาง ระบุจำนวนที่เจ้าของอนุมัติ ท่านได้รับเต็มจำนวนแม้หยุดกลางคัน]

## 2. การเข้าร่วมเป็นความสมัครใจ

- ท่าน**ไม่จำเป็นต้องเข้าร่วม** และ**หยุดได้ทุกเมื่อ**โดยไม่ต้องบอกเหตุผล เพียงแจ้งผู้จัดหรือเดินออกจากห้อง
- ท่านเลือก "ไม่ยินยอม / ขอทางเลือกอื่น" ในหน้าผู้เข้าสอบได้ จะไม่มีการเปิดกล้อง ท่านเข้าร่วมกิจกรรมในส่วนที่ไม่ต้องใช้กล้องได้ หรือนั่งสังเกต [ระบุทางเลือก]
- การเข้าร่วม ไม่เข้าร่วม หรือหยุดกลางคัน **ไม่มีผลต่อคะแนน ผลการเรียน การจ้างงาน การประเมินงาน หรือสิทธิใด ๆ ของท่าน**
- กิจกรรมนี้รับเฉพาะผู้ที่มีอายุ **20 ปีบริบูรณ์ขึ้นไป**

## 3. กล้องเห็นอะไร และระบบทำอะไร

- กล้องเว็บแคมของเครื่องที่ท่านนั่งเห็นใบหน้าและส่วนบนของร่างกายท่าน **ไม่มีการบันทึกเสียง** ระบบไม่เปิดไมโครโฟน
- ระบบดูว่าในภาพมีใบหน้าหรือไม่ มีกี่ใบหน้า ศีรษะหันไปทางใด และมีโทรศัพท์ หนังสือ หรือจออื่นในภาพหรือไม่ แล้วแจ้งเป็น "ข้อสังเกต" เช่น "ไม่เห็นใบหน้า 10 วินาที"
  เพื่อให้ผู้คุมสอบไปดูเอง
- ระบบจดเหตุการณ์ของหน้าเว็บด้วย: ออกจากเต็มจอ สลับแท็บหรือหน้าต่าง คัดลอก วาง (จดเฉพาะจำนวนตัวอักษรที่วาง **ไม่จดข้อความ**) พิมพ์หน้า มีจอที่สอง
  ออฟไลน์/ออนไลน์ และเช็กชื่ออุปกรณ์กล้องที่เครื่องรายงานเพื่อดูว่าเป็นกล้องเสมือน (เช่น OBS) หรือไม่ (ชื่ออุปกรณ์ไม่ถูกเขียนลงไฟล์ส่งออก จดเพียงชนิดเหตุการณ์ "กล้องเสมือน")
- **ระบบไม่บันทึกปากขยับในการนำร่องนี้** [ผู้จัดตรวจก่อนวันว่าติ๊กช่อง "บันทึกปากขยับต่อเนื่อง" ออกแล้ว]
- การประมวลผลทำ**ในเครื่องที่ท่านนั่งเท่านั้น** ภาพจากกล้องไม่ถูกส่งออกทางอินเทอร์เน็ต หน้าเว็บและไฟล์โมเดลถูกดาวน์โหลดจากอินเทอร์เน็ตตอนเปิดหน้า แต่ภาพของท่านไม่ถูกอัปโหลด
- ระบบ**ไม่จดจำใบหน้า ไม่ระบุว่าท่านเป็นใคร ไม่วิเคราะห์อารมณ์หรือสีหน้า ไม่ตรวจจับการโกหก ไม่แสดงหรือจัดอันดับคะแนนความน่าสงสัยของบุคคล และไม่ตัดสินพฤติกรรมของท่าน**
  สิ่งที่ระบบแสดงเป็นเพียงข้อเท็จจริง เช่น "พบโทรศัพท์ในภาพ" ระบบติดป้ายระดับ (ข้อมูล / เฝ้าดู / ควรตรวจ) ให้เหตุการณ์แต่ละรายการ
  เพื่อบอกผู้คุมสอบว่าควรไปดูที่นั่งไหนก่อน ระดับนี้ไม่ใช่คำตัดสิน ผู้คุมสอบเป็นผู้ตัดสินเสมอ
- เราวัดว่า**ระบบ**แจ้งถูกหรือผิด ไม่ได้วัดตัวท่าน

## 4. ข้อมูลที่เก็บ

| ข้อมูล | เก็บหรือไม่ | รายละเอียด |
|---|---|---|
| บันทึกเหตุการณ์ของระบบบนเครื่องที่ท่านนั่ง | เก็บ | เวลา หมายเลขห้องและที่นั่ง ชนิดเหตุการณ์ ระดับ (ข้อมูล / เฝ้าดู / ควรตรวจ) ระยะเวลา อยู่ในเบราว์เซอร์ของเครื่องนั้น แล้วส่งออกเป็นไฟล์ JSON นำเข้าแดชบอร์ดของผู้จัด **ไม่มีภาพ ไม่มีเสียง ไม่มีชื่อ ไม่มีข้อความที่ท่านพิมพ์** |
| ผลการตรวจแสง การปรับเทียบท่าศีรษะ | ใช้ชั่วคราว | ค่าตัวเลขของการติดตั้งและท่าศีรษะเริ่มต้นของท่านใช้ระหว่างกิจกรรมเท่านั้น ไม่ส่งออกเป็นไฟล์ บันทึกเฉพาะว่าคำตัดสินแสงเป็นดี/พอใช้/แย่ |
| แผ่นบันทึกของผู้บันทึก | เก็บ | ผู้บันทึกในห้องจดเวลาตามบทและหมายเลขที่นั่งของเหตุการณ์ **ไม่มีชื่อ** |
| แบบสอบถามหลังกิจกรรม | เก็บ | คะแนน 1–5 "ยุติธรรมและเข้าใจ" **ไม่ใส่ชื่อ** |
| ชื่อของท่าน | เฉพาะในหนังสือฉบับนี้ | เก็บแยกจากข้อมูลข้างต้น เราไม่จดว่าใครนั่งที่นั่งใด หลังจบกิจกรรมจึงไม่สามารถโยงหมายเลขที่นั่งกลับมาที่ตัวท่านได้ |
| ภาพถ่ายห้อง | เก็บ | ถ่ายเฉพาะตอน**ไม่มีคน**ในห้อง |
| ภาพหรือวิดีโอของท่าน | **ไม่เก็บ** | ระบบไม่บันทึกภาพ วิดีโอ หรือคลิปหลักฐาน (ฟังก์ชัน "คลิปหลักฐาน" ปิดอยู่) ไม่มีการจับภาพหน้าจอที่มีคนอยู่ในภาพ |

ข้อมูลที่ไม่มีชื่อข้างต้นใช้เพื่อคำนวณตัวเลขความแม่นยำและเขียนรายงานผล ตัวเลขรวมอาจถูกเผยแพร่ในรายงาน ไฟล์บันทึกเหตุการณ์และ CSV ที่มีหมายเลขที่นั่งและเวลา
**ลบภายในวันที่ [วันที่ — ข้อเสนอ: ไม่เกิน 14 วันหลังวันจัด ตามตารางใน `docs/pilot/PILOT-EXAM.md` §3]** ข้อมูลในเบราว์เซอร์ของเครื่องห้อง **ลบในวันจัด** หลังส่งออกแล้ว
หนังสือฉบับนี้เก็บไว้ถึงวันที่ [วันที่] แล้วทำลาย ท่านขอให้ยืนยันการลบได้ทางช่องทางติดต่อข้างต้น

## 6. สิทธิของท่าน

- ขอหยุดได้ทุกเมื่อ (ข้อ 2) และถอนความยินยอมได้ทุกเมื่อโดยแจ้งผู้จัด
- ถ้าต้องการให้ลบบันทึกเหตุการณ์ของที่นั่งที่ท่านนั่ง ให้แจ้งหมายเลขที่นั่งแก่ผู้จัด**ภายในวันจัดกิจกรรม** หลังจากนั้นเราไม่มีข้อมูลที่บอกได้ว่าที่นั่งใดเป็นของท่าน
- ขอดูหรือขอสำเนาหนังสือฉบับนี้ สอบถาม หรือร้องเรียนได้ที่ช่องทางติดต่อข้างต้น และมีสิทธิร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล
- ความเสี่ยงที่อาจมี: ความไม่สบายใจที่มีกล้องจ้องหน้า ข้อสังเกตของระบบอาจผิดพลาด (เป็นเหตุที่เรากำลังวัด) และความเมื่อยจากการนั่งนาน ท่านพักหรือหยุดได้ทุกเมื่อ
  ข้อสังเกตของระบบไม่ถูกนำไปใช้ตัดสินท่านในเรื่องใด ๆ
