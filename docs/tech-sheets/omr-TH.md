## ใช้ทำอะไร

สองบรรทัดที่แสดงบนหน้าเว็บ (คำตัดสินข้อ 223-7):

- ตรวจกระดาษคำตอบด้วยกล้องมือถือ แสดงคะแนนและสถิติรายข้อ
- แผ่นที่ระบายจาง ระบายเกินวง หรือถ่ายเอียงอาจอ่านผิด ระบบทำเครื่องหมายแผ่นที่ไม่แน่ใจไว้ให้ครูตรวจ

## ตัวเลขที่วัดได้

ทุกตัวเลขระบุที่มา (ข้อมูลจำลอง / ชุดข้อมูลสาธารณะ / หน้างานจริง) ตามข้อความเดิม ตัวเลขไม่ได้พิมพ์ซ้ำด้วยมือ

### บรรทัดการ์ดหมวดและเหตุผลสถานะเดิม (tools/cat-data.cjs ก่อนข้อ 223)

- `cat.c.omrNone` · ที่มา: none (ยังไม่ได้วัด) · อ้างอิง: tests/unit/omr.test.js (synthetic sheets, pass/fail only)
  - TH: ยังไม่ได้วัดกับกระดาษคำตอบที่สแกนจริง มีเพียงชุดทดสอบอัตโนมัติด้วยภาพสังเคราะห์ ครูตรวจแผ่นที่ระบบทำเครื่องหมายไว้
  - EN: Not measured on real scanned sheets; only automated tests on synthetic sheets. The teacher reviews flagged sheets
  - 中文: 尚未用真实扫描答题卡测量；仅有使用合成答题卡的自动化测试。教师复核被标记的答题卡
- `cat.r.omr`
  - TH: ใช้งานได้ครบ แต่ยังไม่ได้วัดกับกระดาษคำตอบที่สแกนจริง
  - EN: Works end to end, but it is not measured on real scanned sheets yet
  - 中文: 流程可用，但尚未用真实扫描答题卡测量

## ข้อจำกัดที่รู้

- รอยฝนจางหรือเลยช่อง หรือภาพเอียง อาจอ่านผิด แผ่นที่ไม่แน่ใจจะถูกส่งให้ครูตรวจ
