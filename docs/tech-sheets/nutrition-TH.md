## ใช้ทำอะไร

สองบรรทัดที่แสดงบนหน้าเว็บ (คำตัดสินข้อ 223-7):

- อ่านฉลากโภชนาการบนเครื่องนี้ แสดงค่าพร้อมบรรทัดที่อ่านมา และให้แก้ไขได้
- ตัวอักษรเล็ก ฉลากโค้ง หรือแสงสะท้อนอาจทำให้ค่าผิด เทียบกับฉลากจริงทุกครั้ง ไม่ใช่คำแนะนำทางการแพทย์

## ตัวเลขที่วัดได้

ทุกตัวเลขระบุที่มา (ข้อมูลจำลอง / ชุดข้อมูลสาธารณะ / หน้างานจริง) ตามข้อความเดิม ตัวเลขไม่ได้พิมพ์ซ้ำด้วยมือ

### บรรทัดการ์ดหมวดและเหตุผลสถานะเดิม (tools/cat-data.cjs ก่อนข้อ 223)

- `cat.c.nut` · ที่มา: none (ยังไม่ได้วัด) · อ้างอิง: docs/nutrition/NUTRITION-ACCURACY.md (synthetic labels only; real label photos not measured yet)
  - TH: ยังไม่ได้วัดกับภาพฉลากจริง ผลทดสอบมีเฉพาะกับฉลากที่สร้างขึ้นเอง ค่าทุกค่าแสดงพร้อมบรรทัดที่มาให้ผู้ใช้ตรวจกับฉลาก
  - EN: Not measured on photos of real labels yet; tested on generated labels only. Every value is shown with its source line for the user to check
  - 中文: 尚未用真实标签照片测量，仅用生成的标签测试。每个数值都附来源行，供用户与标签核对
- `cat.r.nutrition`
  - TH: อ่านฉลากบนเครื่องได้ครบขั้นตอน แสดงค่าตามฉลากพร้อมบรรทัดที่มาและให้ผู้ใช้แก้ได้ ยังไม่ได้วัดกับภาพฉลากจริง ยังไม่มีโหมดประมาณจากภาพอาหาร
  - EN: Reads a label on the device end to end, shows values as printed with their source line and lets the user correct them; not measured on real label photos; the food-photo mode is not built yet
  - 中文: 可在本机完整读取标签，按标签显示数值并附来源行，用户可修改；尚未用真实标签照片测量；食物照片估算模式尚未开发

## ข้อจำกัดที่รู้

- ตัวอักษรเล็ก ฉลากโค้ง หรือแสงสะท้อนทำให้ค่าผิดได้ เทียบกับฉลากจริงเสมอ
- ไม่ใช่คำแนะนำทางการแพทย์
