> **เอกสารภายใน / มอบให้ผู้ซื้อเมื่อขอ — ตัวเลขที่วัดได้และแหล่งที่มา (คำตัดสินของเจ้าของ ข้อ 223)**

สร้างโดย `node tools/tech-sheets.mjs` จาก `docs/tech-sheets/ORIGINAL-FIGURES-223.json` (sha256 93cff21370ba…), `docs/accuracy-figures.json` และทะเบียนใน `docs/ACCURACY-CLAIMS.md` ห้ามแก้ด้วยมือ

หน้าเว็บ: booth.html

## ใช้ทำอะไร

สองบรรทัดที่แสดงบนหน้าเว็บ (คำตัดสินข้อ 223-7):

- นับผู้เข้าชมบูธ ไม่เก็บข้อมูลใบหน้าเป็นค่าเริ่มต้น
- นับเฉพาะคนที่หันหน้ามาทางกล้อง ใช้ดูแนวโน้มมากกว่ายอดจริง

## ตัวเลขที่วัดได้

ทุกตัวเลขระบุที่มา (ข้อมูลจำลอง / ชุดข้อมูลสาธารณะ / หน้างานจริง) ตามข้อความเดิม ตัวเลขไม่ได้พิมพ์ซ้ำด้วยมือ

### ตัวเลขใน docs/accuracy-figures.json

- `boothTar`: ค่า **73** (ค่าดิบ 72.6) — faces 1:1 at 0.50 (booth returning-visitor option): same person accepted — หลักฐานใน `ACCURACY.md`: `**72.6% [69.7–75.3%]**`

### ข้อความตัวเลขเดิมบนหน้าเว็บ (สร้างจาก docs/accuracy-figures.json)

- `booth.s4` (booth.html)
  - นับผู้เข้าชมจากใบหน้าที่หันมาทางกล้อง คนที่ไม่หันหน้ามาจะไม่ถูกนับ · ตัวเลือกจำคนเดิม (ปิดไว้เป็นค่าเริ่มต้น) ใช้เกณฑ์ 0.50 ซึ่งทดสอบกับ LFW จำคนเดิมได้ราว 73% ต่อคู่ภาพ จึงอาจนับคนเดิมซ้ำได้บ้าง ยังไม่ได้วัดกับวิดีโอบูธจริง ใช้ดูแนวโน้มมากกว่ายอดที่แม่นทุกคน และใช้ “ตรวจความแม่นยำหน้างาน” ด้านล่างนับเทียบที่บูธของคุณ
- `booth.lic` (booth.html)
  - ใบหน้าวิเคราะห์ด้วยโมเดล face-api.js (โค้ด MIT) ที่ฝึกจากชุดข้อมูลซึ่งอนุญาตเฉพาะงานวิจัย สิทธิ์ใช้เชิงพาณิชย์ยังไม่ได้รับการยืนยันจากนักกฎหมาย — ตรวจสิทธิ์ก่อนใช้งานเชิงพาณิชย์
- `booth.licb` (booth.html)
  - โมเดลใบอนุญาตวิจัย

### บรรทัดการ์ดหมวดและเหตุผลสถานะเดิม (tools/cat-data.cjs ก่อนข้อ 223)

- `cat.c.boothNone` · ที่มา: none (ยังไม่ได้วัด) · อ้างอิง: ACCURACY.md §9
  - TH: การนับผู้เข้าชมบูธยังไม่ได้วัด (ยังไม่มีวิดีโอที่มีค่าอ้างอิง)
  - EN: Booth visitor counting is not measured (no video with a reference count yet)
  - 中文: 展位访客计数尚未测量（尚无带参考计数的视频）
- `cat.c.boothFace` · ที่มา: public (ชุดข้อมูลสาธารณะ) · อ้างอิง: ACCURACY.md §2 (boothTar, LFW View-1 pairs)
  - TH: ตัวเลือกจดจำผู้กลับมาเยือน: ยอมรับคนเดิมถูก 73% (เทียบ 1:1 ที่เกณฑ์ 0.50) · n = 1,100 คู่ภาพคนเดียวกัน (LFW)
  - EN: Returning-visitor option: the same person is accepted in 73% (1:1 at threshold 0.50) · n = 1,100 same-person pairs (LFW)
  - 中文: 回访识别选项：同一人通过率 73%（1:1，阈值 0.50）· n = 1,100 对同一人照片（LFW）
- `cat.r.booth`
  - TH: การนับผู้เข้าชมยังไม่ได้วัด (ค่าเริ่มต้นคือนับอย่างเดียว ไม่เก็บข้อมูลใบหน้า)
  - EN: Visitor counting is not measured (count-only mode is the default, no face data kept)
  - 中文: 访客计数尚未测量（默认仅计数，不保存人脸数据）

## ข้อจำกัดที่รู้

- นับเฉพาะคนที่หันหน้าเข้ากล้อง ใช้ดูแนวโน้ม ไม่ใช่ยอดที่แน่นอน
- ไม่เก็บข้อมูลใบหน้าโดยค่าเริ่มต้น

## สัญญาอนุญาต

- face-api.js (โค้ด MIT; โมเดลใบอนุญาตวิจัย F5/F6 ปิดในรุ่นลูกค้า)
- รายละเอียดและสถานะการใช้เชิงพาณิชย์ของทุกโมเดลและข้อมูล: `LICENSES/THIRD_PARTY.md`
