**EN.** Two parts.
- **Part A** is the notice the **Customer (data controller)** shows to Data Subjects (students / candidates, staff, visitors, drivers, event attendees).
  The Customer keeps only the "variant" for each product in use and fills it to match the real settings and retention.
- **Part B** is **LENSIQ's own notice as processor.** The Customer may attach or link it for Data Subjects who ask.
- This notice does not replace on-site signs and consent forms (see `CONSENT-FORMS.md`). The notice for the LENSIQ website itself is `privacy.html`.

# ส่วน ก (ไทย): ประกาศความเป็นส่วนตัวของลูกค้า

## ก-1 ส่วนที่ใช้ร่วมกัน (ทุกผลิตภัณฑ์)

**ผู้ควบคุมข้อมูลส่วนบุคคล:** [ชื่อลูกค้า] ที่อยู่ [ที่อยู่] ติดต่อ [ชื่อ / โทร / อีเมล]
**เจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล (DPO) / ผู้ติดต่อ:** [ชื่อ / อีเมล หรือ “ไม่มี DPO ผู้ติดต่อคือ ...”]
[คำถามสำหรับทนาย: P8 ลูกค้าแต่ละประเภท (โรงเรียน หน่วยงานรัฐ นิติบุคคลหมู่บ้าน) ต้องมี DPO ตามมาตรา 41 หรือไม่]

**ระบบที่ใช้:** ซอฟต์แวร์ LENSIQ **ประมวลผลภาพบนอุปกรณ์ของ [ชื่อลูกค้า] ในสถานที่นี้** ภาพจากกล้องไม่ถูกส่งออกทางอินเทอร์เน็ต
และ LENSIQ (ผู้ให้บริการซอฟต์แวร์) โดยค่าเริ่มต้น **ไม่ได้รับ** ข้อมูลส่วนบุคคลของท่าน

**สิ่งที่ระบบไม่ทำ:** ไม่วิเคราะห์อารมณ์หรือสีหน้า ไม่ตรวจจับการโกหกหรือการหลอกลวง ไม่ตัดสินหรือลงโทษท่านโดยอัตโนมัติ คนเป็นผู้ตรวจและตัดสินใจเสมอ

**สิทธิของท่าน** (ตามมาตรา 30–36) ขอเข้าถึงและขอสำเนา ขอแก้ไข ขอให้ลบหรือทำให้ไม่ระบุตัวตน คัดค้าน ขอระงับการใช้ ขอโอนย้ายข้อมูล (ถ้าเข้าข่าย)
และถอนความยินยอมได้ทุกเมื่อ (การถอนไม่กระทบการประมวลผลที่ทำไปแล้ว) ติดต่อได้ที่ผู้ติดต่อข้างต้น
ท่านมีสิทธิร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (สคส./PDPC)
หมายเหตุ: ข้อมูลที่ [ชื่อลูกค้า] ต้องเก็บตามกฎหมาย (เช่น บันทึกเวลาทำงาน ใบเสร็จ) ลบก่อนครบกำหนดไม่ได้

**ผู้รับข้อมูล:** เจ้าหน้าที่ของ [ชื่อลูกค้า] ที่ได้รับมอบหมาย และหน่วยงานรัฐเมื่อมีหน้าที่ตามกฎหมาย
ผู้ให้บริการซอฟต์แวร์ LENSIQ เข้าถึงข้อมูลเฉพาะเมื่อให้การสนับสนุนต่อหน้า [ชื่อลูกค้า] หรือตามสัญญาประมวลผลข้อมูล [ถ้ามี: ระบุ]

**การส่งข้อมูลไปต่างประเทศ:** [ไม่มี / ระบุ เช่น ใช้บริการซิงก์บนคลาวด์ที่ Cloudflare ซึ่งเป็นบริษัทสหรัฐฯ มีเซิร์ฟเวอร์นอกประเทศไทย]
[คำถามสำหรับทนาย: P6 กลไกตามมาตรา 28–29 สำหรับกรณีที่ลูกค้าเปิดใช้บริการซิงก์ ดู L22]

**ความปลอดภัย:** ข้อมูลใบหน้า (ถ้ามี) เข้ารหัสบนอุปกรณ์ จำกัดผู้เข้าถึงด้วยรหัสผ่าน/PIN บันทึกการแก้ไขเป็นแบบเพิ่มต่อท้าย ตรวจสอบย้อนหลังได้

## ก-2 แบบประกอบ: Exam (โหมดห้องปฏิบัติการ) — สำหรับผู้เข้าสอบ

| หัวข้อ | ข้อความ |
|---|---|
| ผู้ที่ประกาศนี้ใช้กับ | ผู้เข้าสอบที่ใช้คอมพิวเตอร์ของ [สถาบัน] ในห้องสอบ [ห้อง] |
| วัตถุประสงค์ | ช่วยผู้คุมสอบให้ไปดูที่นั่งที่อาจมีเหตุผิดปกติ เพื่อรักษาความเป็นธรรมของการสอบ |
| กล้องตรวจอะไร | ใบหน้าไม่อยู่ในภาพ มีหลายใบหน้าหรือมีคนอื่นในภาพ มีโทรศัพท์หรือวัตถุที่อาจเป็นสิ่งต้องห้ามในภาพ ออกจากหน้าจอสอบ ที่นั่งว่าง/มีคนเพิ่ม (โหมดห้อง) |
| ข้อมูลที่เก็บ | บันทึกเหตุการณ์: เวลา หมายเลขที่นั่ง ชนิดสัญญาณ ผลที่ผู้คุมสอบบันทึก ชื่อผู้คุมสอบที่บันทึก **ไม่เก็บภาพโดยค่าเริ่มต้น ไม่บันทึกเสียง** |
| คลิปหลักฐาน (ตัวเลือก ปิดเป็นค่าเริ่มต้น) | ถ้า [สถาบัน] เปิด: เก็บคลิปสั้นประมาณ 10 วินาทีรอบเหตุการณ์ **เมื่อผู้คุมสอบที่มีชื่อกด “เก็บ”** [หรือเก็บอัตโนมัติ] ไม่มีเสียง เข้ารหัสในเครื่องที่ใช้สอบเท่านั้น ลบอัตโนมัติใน [14] วัน (ตัวเลือก 1/7/14/30/90) |
| ฐานทางกฎหมาย | [เลือก: ภารกิจเพื่อประโยชน์สาธารณะของสถาบัน มาตรา 24(4) / ประโยชน์โดยชอบด้วยกฎหมาย มาตรา 24(5) / ความยินยอม] [คำถามสำหรับทนาย: ฐานสำหรับสถาบันรัฐกับเอกชน และถ้าใช้ความยินยอมต้องมีทางเลือกจริง — ดู README ข้อ B1] |
| ระยะเวลาเก็บ | บันทึกเหตุการณ์ไม่เกิน [90] วันหรือตามระเบียบของสถาบัน คลิป [14] วัน ข้อมูลโปรไฟล์ที่นั่งพิเศษ (ถ้ามี) สิ้นสุดภายใน 24 ชั่วโมงหลังสอบ |
| ผู้ที่เห็นข้อมูล | ผู้คุมสอบและผู้รับผิดชอบการสอบของสถาบัน ผู้เข้าสอบคนถัดไปบนเครื่องเดียวกันเห็นเพียงจำนวนคลิป |
| การตัดสินใจ | **ไม่มีการตัดสินว่าทุจริตโดยอัตโนมัติ** สัญญาณเป็นเพียงเหตุให้ผู้คุมสอบไปดู ผู้คุมสอบตรวจและบันทึกผลเอง |
| ท่านไม่ยินยอมได้ไหม | ได้ ท่านขอสอบโดยไม่เปิดกล้องหรือโดยวิธีอื่นที่ [สถาบัน] จัดให้ได้ โดยไม่เสียสิทธิในการสอบ แจ้งก่อนวันสอบอย่างน้อย [7] วันที่ [ช่องทาง] |
| ผู้เยาว์ | ผู้เข้าสอบอายุต่ำกว่า 20 ปี [ต้องมีความยินยอมของผู้ปกครอง / ตามระเบียบสถาบัน] [คำถามสำหรับทนาย: P7 / s.20] |
| ข้อควรรู้ | ระบบอาจแจ้งผิดหรือพลาดบางเหตุ นอกจากนี้ผู้ที่นั่งใกล้กันอาจอยู่ในภาพ [ติดป้ายในห้อง] |

## ก-3 แบบประกอบ: Attendance (เช็คชื่อ/ลงเวลา) — สำหรับพนักงานและผู้เข้าอบรม

| หัวข้อ | ข้อความ |
|---|---|
| ผู้ที่ประกาศนี้ใช้กับ | พนักงาน/ผู้เข้าอบรมของ [ชื่อลูกค้า] ที่ลงเวลาด้วยระบบนี้ |
| วิธีลงเวลา | **PIN หรือ QR บัตร เป็นวิธีมาตรฐาน** การใช้ใบหน้าเป็นตัวเลือกเท่านั้น |
| ข้อมูลที่เก็บ (ทุกคน) | ชื่อ รหัสพนักงาน เวลาเข้า-ออก การลา/แก้ไขเวลาที่ผู้จัดการบันทึก (เพิ่มต่อท้าย ตรวจย้อนหลังได้) PIN เก็บเป็นค่าแฮชแบบใส่เกลือ ไม่เก็บ PIN จริง |
| ข้อมูลใบหน้า (เฉพาะผู้ที่ยินยอมแยกต่างหาก) | **ค่าตัวเลขลักษณะใบหน้า (ข้อมูลชีวมิติ มาตรา 26)** ไม่ใช่รูปถ่าย เข้ารหัสบนเครื่องลงทะเบียน ไม่ส่งออก ลบอัตโนมัติเมื่อไม่ได้ใช้เกิน [365] วัน (ตั้งได้ 30–730) [หรือภายใน 30 วันหลังจบหลักสูตร] ท่านลบข้อมูลใบหน้าเองได้ที่ [ช่องทาง] |
| ฐานทางกฎหมาย | บันทึกเวลา: หน้าที่ตามกฎหมาย/สัญญาจ้าง (มาตรา 24(6) / 24(3)) · ใบหน้า: ความยินยอมโดยชัดแจ้ง (มาตรา 26) [คำถามสำหรับทนาย: P2 ความยินยอมในบริบทการจ้างงานมีผลสมัครใจหรือไม่ แม้มี PIN/QR เป็นทางเลือก — ดู PDPA-NOTES B2] |
| ระยะเวลาเก็บ | บันทึกเวลาและค่าจ้างอย่างน้อย **2 ปี** (ตั้งได้ 2/3/5/10 ปี ต่ำกว่า 2 ปีไม่ได้) ตามพระราชบัญญัติคุ้มครองแรงงาน มาตรา 114 [คำถามสำหรับทนาย: ยืนยันมาตราและระยะเวลา] · ข้อมูลใบหน้าแยกต่างหาก เป็นไปตามข้างบน การลบข้อมูลใบหน้าไม่ลบบันทึกเวลา |
| ทางเลือก | ท่านเลือก PIN/QR แทนใบหน้าได้ **โดยไม่มีผลเสียต่อการจ้างงานหรือการประเมิน** ถอนความยินยอมได้ทุกเมื่อ |
| การตัดสินใจ | ไม่มีการตัดสินโดยอัตโนมัติ ผู้จัดการตรวจรายการผิดปกติ และการแก้ไขทุกครั้งมีผู้บันทึกชื่อ |

## ก-4 แบบประกอบ: Gate (ป้ายทะเบียน) — สำหรับคนขับ ผู้พักอาศัย ผู้มาติดต่อ

| หัวข้อ | ข้อความ |
|---|---|
| ผู้ที่ประกาศนี้ใช้กับ | ผู้ขับขี่และเจ้าของรถที่เข้า-ออก [ชื่อสถานที่] ผ่านจุดกล้องอ่านป้ายทะเบียน |
| วัตถุประสงค์ | [คิดค่าจอด / ควบคุมการเข้าออกและความปลอดภัยของโครงการ] |
| ข้อมูลที่เก็บ | เลขทะเบียน จังหวัด เวลาเข้า-ออก ช่องทาง/จุด ชื่อเจ้าหน้าที่ผู้ยืนยัน ค่าบริการและวิธีชำระ (ถ้ามี) บ้านเลขที่ที่ลงทะเบียน (หมู่บ้าน/คอนโด) ชื่อและเบอร์โทรผู้มาติดต่อที่เจ้าหน้าที่กรอก (ถ้ามีบัตรผ่าน) รายการห้ามเข้าพร้อมเหตุผล (ถ้ามี) |
| ภาพ | **ไม่เก็บภาพรถ** ภาพครอปป้าย: [ไม่เก็บ / เก็บ [7] วัน] |
| สิ่งที่ไม่ทำ | ไม่จดจำใบหน้า ไม่ประเมินอารมณ์หรือพฤติกรรม ไม่เปิดไม้กั้นอัตโนมัติ [เว้นแต่ลูกค้าเปิดเองและระบุ] |
| ฐานทางกฎหมาย | ประโยชน์โดยชอบด้วยกฎหมาย (มาตรา 24(5)) และการปฏิบัติตามสัญญาให้บริการ (มาตรา 24(3)) [คำถามสำหรับทนาย: L24 ฐานที่ถูกต้องสำหรับลานจอด กับหมู่บ้าน และผู้มาติดต่อ] |
| ระยะเวลาเก็บ | บันทึกเข้า-ออก [90] วัน (ตั้งได้ 7–730) · ภาพครอปป้าย [7] วัน (1–30) หรือไม่เก็บ · ใบเสร็จ 5 ปีตามกฎหมายบัญชี/ภาษี · รายการห้ามเข้า ทบทวนทุก [180] วัน |
| การตัดสินใจ | ระบบเสนอผลอ่าน **เจ้าหน้าที่ยืนยันหรือแก้ไขทุกครั้ง** การแก้ไขถูกบันทึกแบบแก้ย้อนหลังไม่ได้ |
| ขอแก้/คัดค้าน | ติดต่อ [ป้อมยาม/ช่องทาง] |

# ส่วน ข (ไทย): ประกาศความเป็นส่วนตัวของ LENSIQ ในฐานะผู้ประมวลผลข้อมูล

**ผู้ให้บริการ:** [ชื่อนิติบุคคลผู้ให้บริการ] เลขทะเบียน [เลข 13 หลัก] ที่อยู่ [ที่อยู่] ติดต่อด้านข้อมูลส่วนบุคคล [อีเมล]

**บทบาท:** สำหรับข้อมูลของลูกค้าที่ใช้ผลิตภัณฑ์ Exam, Attendance, Gate และ Crowd ผู้ให้บริการเป็น **ผู้ประมวลผลข้อมูลส่วนบุคคล** (มาตรา 40) ลูกค้าเป็นผู้ควบคุมข้อมูล
ผู้ให้บริการประมวลผลตามคำสั่งเป็นหนังสือของลูกค้าเท่านั้น (ดู DPA) สำหรับเว็บไซต์ บัญชีสมาชิก การชำระเงิน และการขายของผู้ให้บริการเอง
ผู้ให้บริการเป็นผู้ควบคุมข้อมูลแยกต่างหากตาม `privacy.html`

**1. ข้อมูลที่เราได้รับ**
- **โดยค่าเริ่มต้น: ไม่ได้รับข้อมูลส่วนบุคคลของท่าน** ภาพและข้อมูลใบหน้าประมวลผลและเก็บบนอุปกรณ์ของลูกค้า
- เมื่อให้การสนับสนุนทางไกล: อาจเห็นหน้าจอของลูกค้าชั่วคราวต่อหน้าลูกค้า ไม่ขอให้ส่งออกข้อมูลใบหน้า
- เมื่อลูกค้าใช้ศูนย์รวมข้อมูล (`server.py`) ที่เราโฮสต์: ตัวเลขสถิติรวม ไม่ใช่ข้อมูลระบุตัวตน เก็บ 62 วัน
- เมื่อลูกค้าทำโครงการทดลองที่มีการบันทึกวิดีโอ (เฉพาะนับคน): วิดีโอเก็บในไดรฟ์เข้ารหัส ผู้เข้าถึงจำกัด และลบเมื่อจบโครงการ
- เมื่อลูกค้าเปิดบัญชีองค์กรบน Cloudflare (**ยังไม่เปิดให้บริการ**): เฉพาะรายการข้อมูลที่ลูกค้าเลือกซิงก์ตามที่ระบุใน DPA ค่าใบหน้า คลิปหลักฐาน ภาพครอปป้าย และภาพจากกล้อง อยู่บนอุปกรณ์เท่านั้นโดยค่าเริ่มต้น
- เมื่อลูกค้าเปิดบริการ AI ภายนอก (ตัวเลือก ปิดเป็นค่าเริ่มต้น ไม่ใช้กับ Exam, Attendance, Gate, Crowd ในปัจจุบัน): ส่งเฉพาะข้อเท็จจริงที่สกัดแล้ว เมื่อผู้ใช้ยินยอม

**3. ผู้ประมวลผลช่วง:** Cloudflare (โฮสต์ระบบหลังบ้านและฐานข้อมูล เมื่อมีการใช้) และผู้ให้บริการ AI เฉพาะรายที่ลูกค้าเปิดใช้ ตามรายชื่อใน DPA ภาคผนวก 2
