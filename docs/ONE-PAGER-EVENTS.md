# LENSIQ สำหรับงานอีเวนต์และบูธ — ดึงคนเข้าบูธ แล้ววัดผลได้จริง

**ตู้ถ่ายรูป กิจกรรมดูดวง และการนับผู้เข้าชม ในชุดเดียว ทำงานบนแท็บเล็ต/โน้ตบุ๊ก ไม่ต้องต่อคลาวด์**

## ปัญหาของบูธ
- จ่ายค่าบูธและพริตตี้ แต่ไม่รู้ว่ามีคนแวะกี่คน หยุดดูนานแค่ไหน
- กิจกรรมแจกของไม่สร้างการแชร์ต่อ
- ตู้ถ่ายรูปทั่วไปเก็บรูปผู้ร่วมงานบนเซิร์ฟเวอร์ภายนอก

## สิ่งที่ได้
| ระบบ | ผลลัพธ์ |
|---|---|
| วิเคราะห์บูธ (กล้องร้านค้า, `retail.html`) | ผู้เข้าชมไม่ซ้ำรายวัน เวลาหยุดชม ช่วงเวลาคนเยอะ รวมหลายบูธ (ค่าใบหน้าภายในวันลบอัตโนมัติ หรือโหมดนับอย่างเดียว) |
| ตู้ถ่ายรูป / สตูดิโอแต่งชุด (Creative Suite, `creative-suite.html`) | สติ๊กเกอร์ รูปติดบัตร ตัดพื้นหลัง กรอบแบรนด์ พิมพ์หรือดาวน์โหลดเอง ไม่เก็บรูป |
| กิจกรรมดูดวง 15 ศาสตร์ | โหงวเฮ้ง ลายมือ ไพ่ทาโรต์ เซียมซี เลขมงคล ฯลฯ ภาษาไทย อังกฤษ และจีน (เหมาะกับงานที่มีผู้ชมต่างชาติ) การ์ดแชร์ 1080×1350 โหมดคีออสก์ล้างหน้าจออัตโนมัติ |
| วิเคราะห์อารมณ์ | ทดสอบโฆษณาหรือบรรจุภัณฑ์จากสีหน้ากับผู้ร่วมทดสอบที่ยินยอม ¹ |

¹ **หมายเหตุใบอนุญาตและกฎหมาย (วิเคราะห์อารมณ์):** ใช้กับผู้ร่วมทดสอบที่ยินยอมเท่านั้น (PDPA ม.19) ผลเป็นค่าประมาณ — การแสดงออกทางสีหน้าไม่ได้บอกอารมณ์ภายในอย่างน่าเชื่อถือ (Barrett และคณะ, 2019) และโมเดลอ่านได้ถูกราว 52% จาก 7 ประเภท (`ACCURACY.md`) ใช้ดูภาพรวมของสื่อ ไม่ใช้ตัดสินรายบุคคล · **EU AI Act:** มาตรา 5(1)(f) ห้ามระบบรู้จำอารมณ์ในที่ทำงานและสถานศึกษา (ห้ามใช้กับพนักงานบูธหรือนักเรียน) และมาตรา 50(3) กำหนดให้แจ้งผู้ถูกวิเคราะห์เมื่อใช้ในบริบทอื่น — งานในสหภาพยุโรปต้องแจ้งชัดเจนและให้ฝ่ายกฎหมายตรวจก่อน · **ใบอนุญาตโมเดล:** น้ำหนักโมเดลสีหน้า (face-api.js) เป็น MIT แต่ชุดข้อมูลฝึก (แนว FER) มีเงื่อนไขไม่ชัดเจน — สถานะ “ต้องตรวจสอบ” ใน `LICENSES/THIRD_PARTY.md` (F5, A5) ควรได้ความเห็นทางกฎหมายก่อนขายเชิงพาณิชย์

## จุดเด่น
- **ใช้ได้ทันทีในงาน:** โหลดครั้งเดียว ใช้ต่อแม้สัญญาณอินเทอร์เน็ตในฮอลล์ไม่ดี
- **ปลอดภัยต่อแบรนด์:** ดูดวงเพื่อความบันเทิง มีข้อความเตือนใจตามหลักกาลามสูตรทุกคำทำนาย คำเตือนนุ่มนวลพร้อมสิ่งที่ทำได้ ปุ่ม “แจ้งปัญหาคำทำนายนี้”
- **ป้าย PDPA พร้อมพิมพ์** 3 ภาษา (ป้าย A, B, D) ติดหน้าบูธได้เลย
