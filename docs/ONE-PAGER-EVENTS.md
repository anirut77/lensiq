# LENSIQ สำหรับงานอีเวนต์และบูธ — ดึงคนเข้าบูธ แล้ววัดผลได้จริง

**ตู้ถ่ายรูป กิจกรรมดูดวง และการนับผู้เข้าชม ในชุดเดียว ทำงานบนแท็บเล็ต/โน้ตบุ๊ก ไม่ต้องต่อคลาวด์**

## ปัญหาของบูธ
- จ่ายค่าบูธและพริตตี้ แต่ไม่รู้ว่ามีคนแวะกี่คน หยุดดูนานแค่ไหน
- กิจกรรมแจกของไม่สร้างการแชร์ต่อ
- ตู้ถ่ายรูปทั่วไปเก็บรูปผู้ร่วมงานบนเซิร์ฟเวอร์ภายนอก

## สิ่งที่ได้
| ระบบ | ผลลัพธ์ |
|---|---|
| วิเคราะห์บูธ | ผู้เข้าชมไม่ซ้ำรายวัน เวลาหยุดชม ช่วงเวลาคนเยอะ รวมหลายบูธ (ค่าใบหน้าภายในวันลบอัตโนมัติ หรือโหมดนับอย่างเดียว) |
| ตู้ถ่ายรูป / สตูดิโอแต่งชุด | สติ๊กเกอร์ รูปติดบัตร ตัดพื้นหลัง กรอบแบรนด์ พิมพ์หรือดาวน์โหลดเอง ไม่เก็บรูป |
| กิจกรรมดูดวง 15 ศาสตร์ | โหงวเฮ้ง ลายมือ ไพ่ทาโรต์ เซียมซี เลขมงคล ฯลฯ ภาษาไทยและจีน การ์ดแชร์ 1080×1350 โหมดคีออสก์ล้างหน้าจออัตโนมัติ |
| วิเคราะห์อารมณ์ | ทดสอบโฆษณาหรือบรรจุภัณฑ์จากสีหน้ากับผู้ร่วมทดสอบที่ยินยอม |

## จุดเด่น
- **ใช้ได้ทันทีในงาน:** โหลดครั้งเดียว ใช้ต่อแม้สัญญาณอินเทอร์เน็ตในฮอลล์ไม่ดี
- **ปลอดภัยต่อแบรนด์:** ดูดวงเพื่อความบันเทิง มีข้อความเตือนใจตามหลักกาลามสูตรทุกคำทำนาย คำเตือนนุ่มนวลพร้อมสิ่งที่ทำได้ ปุ่ม “แจ้งปัญหาคำทำนายนี้”
- **ป้าย PDPA พร้อมพิมพ์** 3 ภาษา (ป้าย A, B, D) ติดหน้าบูธได้เลย

## แพ็กเกจงาน (ฉบับร่าง — ยืนยันในใบเสนอราคา)
| แพ็กเกจ | ประกอบด้วย |
|---|---|
| Event Day Pass | 1 วัน ผู้ช่วยเขียนคำทำนายตามโควตา รายงานบูธ + ตู้ถ่ายรูป กรอบแบรนด์ |
| Event Week | 7 วัน หลายบูธรวมยอด CSV รายวัน เช็กลิสต์ติดตั้งหน้างาน |
| ฟรี (ผู้เยี่ยมชม/สมาชิก) | ใช้ทุกระบบบนเครื่องได้เองโดยไม่มีค่าใช้จ่าย |

ยกเลิกก่อนวันงาน 7 วันคืนเต็มจำนวน (ตามข้อกำหนดฉบับร่าง)
