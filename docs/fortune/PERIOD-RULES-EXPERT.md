## หลักร่วม (ทุกหน้า)
- พื้นดวง (ฐาน) คำนวณจากข้อมูลเกิดเท่านั้น เมื่อเปิดสวิตช์ seed ของถ้อยคำไม่อ่านนาฬิกา ข้อความจึงเหมือนเดิมทุกวัน
- ช่วงเวลา = เดือนสุริยคติจีน เริ่มที่สารทจีน (節: 立春 315°, 驚蟄 345°, 清明 15°, ... ทุก 30°) เพราะทั้งเสาเดือนปาจื้อและดาวเหินประจำเดือนเปลี่ยนที่จุดนี้
  ไม่ใช่วันที่ 1 ของเดือนปฏิทิน หน้าเว็บบอกช่วงพร้อมวันที่ เช่น "ช่วงนี้: 7 พ.ย. – 7 ธ.ค. 2569"
- ความแม่นที่ต้องใช้: ระบุได้ว่าวันหนึ่งอยู่เดือนสุริยคติใด (ระดับวัน) · ที่ให้: ลองจิจูดดวงอาทิตย์แบบย่อของ Meeus บทที่ 25 (โค้ดของเราเอง
  ประมาณ 0.01° หรือราว 15 นาที) ไม่ใช้ ephemeris ภายนอก (astronomy-engine รอการตัดสิน 236 จึงไม่ได้ใช้)
- ข้อความช่วงนี้ seed จาก (ข้อเท็จจริงของดวง + รหัสช่วง) ไม่มีการสุ่ม ช่วงเดียวกันได้ข้อความเดิม ช่วงใหม่ได้ข้อเท็จจริงใหม่
- น้ำเสียงเตือน (ระวัง) อยู่ในระดับเดือนเท่านั้น คำว่า "วันนี้" ในวลีที่ยืมมาจะถูกเปลี่ยนเป็น "ช่วงนี้" และเทสต์ห้ามคำระดับวันในข้อความช่วงนี้
- เรียบเรียงในเครื่องด้วย fortune-ai.js (ไม่ใช้ AI ภายนอก) ตาข่ายวิกฤตมาก่อนเสมอ ทุกประโยคผ่านตัวกรองขีดจำกัดเด็ดขาดซ้ำอีกรอบ
  ไม่มีแผน ราคา ปุ่มซื้อ หรือลิงก์ในกล่องนี้ หน้า calm/วิกฤต ซ่อนคำแนะนำเสริมดวง

## วลีของโครงกลาง (`fortune-period.js` PHRASES)
สถานะ draft = วลีใหม่ รอผู้เชี่ยวชาญและเจ้าของ · reviewed = ใช้บนหน้าอยู่แล้ว

| คีย์ | สถานะ | ไทย |
|---|---|---|
| `heading` | draft | ดวงช่วงนี้ |
| `label` | draft | ช่วงนี้: {ช่วงวันที่} |
| `constant` | draft | คำทำนายพื้นดวงด้านบนคำนวณจากข้อมูลเกิด จึงเหมือนเดิมทุกครั้ง ส่วนนี้คำนวณใหม่เมื่อเข้าช่วงใหม่ |
| `solarMonth` | draft | ช่วงเวลานับตามเดือนสุริยคติจีน ซึ่งเริ่มที่สารทจีน (節) ตามตำรา |
| `noMethod` | draft | ศาสตร์นี้ไม่มีวิธีดูตามช่วงเวลา คำทำนายในหน้านี้จึงเป็นพื้นดวงอย่างเดียว |
| `belief` | reviewed | ตามความเชื่อ โปรดใช้วิจารณญาณ |
| `methodHoroscope` | draft | คำนวณจากเสาเดือน (ปาจื้อ 流月) ของช่วงนี้เทียบธาตุประจำตัว และกิ่งเดือนเทียบปีนักษัตรของคุณ |
| `methodFengshui` | draft | คำนวณจากดาวเหินประจำปี (เริ่มที่ลี่ชุน) และดาวเหินประจำเดือนของช่วงนี้ เทียบกับห้องในผังบ้านของคุณ |
| `factMonthPillar` | draft | เสาเดือนของช่วงนี้: {เสา} (ธาตุ{ธาตุ}) |

| `noMethodDraw` | draft | ศาสตร์นี้เป็นการเสี่ยงทาย ผลสุ่มใหม่ทุกครั้งที่ทำ จึงไม่มีชั้นดวงช่วงนี้แยก |
| `constantNoBase` | draft | หน้านี้ไม่ใช้ข้อมูลเกิด จึงไม่มีพื้นดวง คำแนะนำนี้เปลี่ยนตามวัน |
| `methodZodiac` | draft | คำนวณจากกิ่งของเดือนสุริยคติจีน (流月) ของช่วงนี้เทียบปีนักษัตรของคุณ |

| `factSunSign` | draft | ดวงอาทิตย์จรอยู่ราศี{ราศี} · เรือนที่ {เลข} นับจากราศีอาทิตย์ของคุณ |

ชื่อกิ่ง ราศี ความสัมพันธ์ และวันในสัปดาห์ (ตาราง `BR`, `SIGN`, `REL`, `DAY_N` ใน fortune-period.js) เป็นคำเรียกมาตรฐาน อยู่ในรายการตรวจนี้ด้วย
ในภาษาอังกฤษและจีน ประโยคแรกของคำอ่าน (ประโยคเปิดแบบดวงกำเนิด) ไม่แสดงในกล่องช่วงนี้

คำอ่านในกล่องมาจากตารางวลีที่ตรวจแล้ว (horoscope-kb.js `R.rel`, `R.branch`; fengshui-kb.js `flying`; i18n/en-kb-*, zh-kb-*) ไม่มีวลีทำนายใหม่
การแปลงคำระดับวันเป็นช่วง (`localize`: วันนี้ → ช่วงนี้, today → this period, 今天 → 本月) ก็อยู่ในรายการตรวจนี้ด้วย
