## ก่อนเริ่มทุกผลิตภัณฑ์ (ทำครั้งเดียว 3 นาที)

1. ที่อยู่หน้าเว็บ: `https://anirut77.github.io/lensiq/<ชื่อหน้า>` ต้องเป็น **https** ไม่เช่นนั้นกล้องจะไม่เปิด
2. iPhone ใช้ **Safari** · Android ใช้ **Chrome** จดรุ่นเครื่องและเวอร์ชันระบบ (iPhone: ตั้งค่า > ทั่วไป > เกี่ยวกับ · Android: การตั้งค่า > เกี่ยวกับโทรศัพท์)
3. ชาร์จแบตให้เกิน 50 % ปิดแอปอื่นที่เปิดค้าง เพื่อให้ผลเทียบกันได้
4. ข้อมูลทดสอบใช้ชื่อสมมติเท่านั้น เช่น "ทดสอบ หนึ่ง" ห้ามใช้ชื่อ เลขบัตร เบอร์โทร หรือป้ายทะเบียนของคนจริง
5. คนในกล้องคือตัวคุณเองหรือผู้ช่วยที่ยินยอมแล้ว ภาพประมวลผลสดในเครื่อง ไม่บันทึก ไม่ส่งออก
6. ถ้ากล้องถามสิทธิ์ ให้กด "อนุญาต" ถ้าเผลอกดปฏิเสธ: iPhone ตั้งค่า > Safari > กล้อง · Android แตะรูปกุญแจข้างที่อยู่เว็บ > สิทธิ์

## สิ่งที่ต้องสังเกตทุกผลิตภัณฑ์

- **หน้าโหลดใหม่เอง** (จอขาวแล้วกลับมาที่ต้นหน้า) หรือ Safari ขึ้นว่า "เกิดปัญหาซ้ำ" → จดเวลาและขั้นตอนที่ทำอยู่
- ถ้าเห็นกล่องสีเหลือง **"หน้านี้เพิ่งเริ่มใหม่ ... เราจึงสลับเป็นโหมดเบา"** แปลว่าหน้าเว็บตรวจพบว่าเพิ่งเด้ง และลดความละเอียดกล้องเองแล้ว
  ให้จดว่าเห็นกี่ครั้ง ในหน้าไหน และหลังจากนั้นใช้งานต่อได้หรือไม่ (ไม่ใช่ข้อผิดพลาดของคุณ เป็นข้อมูลที่ทีมต้องการ)
- เครื่องร้อนจนจับไม่สบายมือ, แบตลดเกิน 10 % ใน 15 นาที, ภาพกล้องกระตุกหรือค้าง
- ปุ่มเล็กจนกดพลาด, ตัวหนังสือล้นจอ (ต้องเลื่อนซ้ายขวา), ข้อความไทยปนอังกฤษผิดที่

## สิ่งที่ส่งกลับ (ทุกผลิตภัณฑ์ ใช้แบบฟอร์มเดียวกัน)

ส่งเป็นข้อความเดียวต่อผลิตภัณฑ์ (LINE หรืออีเมลถึงทีม) ตามแบบนี้:

```
ผลิตภัณฑ์: ...                 วันที่/เวลา: ...
เครื่อง 1: iPhone รุ่น ... iOS ...       เครื่อง 2: Android รุ่น ... Android ... Chrome ...
ข้อที่ผ่าน (เลขข้อ): ...
ข้อที่ไม่ผ่าน: เลขข้อ / เครื่อง / อาการ / ข้อความบนจอ (พิมพ์ตามจริง)
หน้าโหลดใหม่เอง: กี่ครั้ง / หน้าไหน / ทำอะไรอยู่      เห็นกล่อง "โหมดเบา": ใช่ / ไม่ใช่
เครื่องร้อน: ไม่ร้อน / อุ่น / ร้อนมาก        แบตเริ่ม ... % จบ ... %
จุดที่งง: ...
```

ภาพหน้าจอส่งได้ **เฉพาะหน้าที่ไม่มีหน้าคน ไม่มีป้ายทะเบียนจริง และไม่มีชื่อจริง** ถ้าภาพมีหน้าคน ให้ส่งเป็นคำบรรยายแทน
