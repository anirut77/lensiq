# LENSIQ — 在您自己的设备上运行的营销与分析计算机视觉

**把现有摄像头变成营销数据：不上传画面，不录制视频，按泰国 PDPA 设计**

## 解决的问题

- 门店和展位不清楚"进来多少人、什么时段人多、在哪里停留最久"，只能凭感觉排班和做促销。
- 常见的智能摄像头方案要把画面上传到云端，月费高，个人数据风险也大。
- 广告屏和拍照亭缺少衡量投入产出的指标。

## LENSIQ 能做什么

| 类别 | 系统 | 产出 |
|---|---|---|
| 门店分析 | 进出客流统计、热力图、排队、多摄像头/多门店 | 每小时报表、时段对比，并给出置信区间 |
| 营销 | 智能广告屏、展位分析、表情测试广告、会员识别（自愿加入） | 广告观看时长、独立访客数、关注度 |
| 拍照亭与工作室 | 抠图、证件照、换装工作室 | 提升活动现场与门店的互动 |
| 趣味占卜 | 11 种玩法（手相、面相、塔罗牌、风水、吉祥数字等） | 为展位引流，生成可分享的结果卡片 |
| 附加系统 | 商品识别、产品质检、人脸签到、驾驶员疲劳提醒、PDF 转 Word | 一个摄像头即可完成后台工作 |

## 为什么选择 LENSIQ

- **100% 本地处理**：在浏览器中运行，断网也能用，不按摄像头收取云端费用。
- **默认保护隐私**：不保存画面；人脸特征值采用 AES-256 加密；不向任何第三方发送数据（字体和所有库都随系统部署）。
- **PDPA 文档齐备**：已填写的 DPIA、处理活动记录（ROPA）、告知与同意文本、保存期限表（使用前须经法务审核）。
- **利用现有摄像头**：网络摄像头、手机、平板均可。多台手机通过门店 Wi-Fi 把统计汇总到主机，只传数字。
- **数字透明**：公开在公共数据集上实测的准确率（`ACCURACY.md`），并提供带验收标准的门店试点方案。
- **泰语与中文**：每个页面都可切换 TH | 中文。
- **默认配置可商用**：不允许商用的组件默认关闭，开启前必须确认授权。

## 三步上线

1. **现场勘察**：摄像头位置、光线和网络（1 天）。
2. **4 周试点**：安装后与人工计数对比，按 `docs/PILOT-PLAN.md` 中的标准验收（例如日客流误差 ≤ 5%）。
3. **正式运行与维护**：按 `docs/SUPPORT.md` 选择 Basic / Standard / Premium 服务套餐。

## 坦诚说明的限制

- 准确率取决于摄像头角度和光线。人很小、距离很远或人群密集时会少计，因此必须先在门店试点。
- 年龄、性别和情绪只是估计值，用于看整体趋势，不用于对个人做判断。
- 占卜仅供娱乐。
