# LENSIQ ดูดวง — 15 ศาสตร์ไทย–จีน อ่านได้ 3 ภาษา สำหรับผู้ใช้ทั่วไปและครีเอเตอร์สายดูดวง

**คำทำนายที่อ่านลื่น อ่อนโยน และอ้างอิงตำรา — เพื่อความบันเทิง ไม่ขู่ ไม่ฟันธง**

หนึ่งใน 4 ผลิตภัณฑ์ของ LENSIQ (ดูดวง · กล้องร้านค้า · ชุดสัมภาษณ์ HR · Creative Suite) ที่ใช้เอนจินเดียวกัน
บัญชี Google เดียวกัน และหลังบ้านเดียวกัน · หน้าแรกของผลิตภัณฑ์: `fortune.html`

## สิ่งที่ได้
| | |
|---|---|
| คำทำนายเด่น | โหงวเฮ้ง ลายมือ ไพ่ทาโรต์ ดวงวันเดือนปีเกิด/แปดอักษร เลขมงคล — เริ่มได้ภายในไม่กี่วินาที |
| ทุกศาสตร์ (15) | โหงวเฮ้ง ลายมือ ดวงวันเดือนปีเกิด แปดอักษร ทักษา เลข 7 ตัว 9 ฐาน กราฟชีวิต ไพ่ทาโรต์ เซียมซี ฮวงจุ้ย เลขมงคล อี้จิง 12 นักษัตร ราศีตะวันตก ทำนายฝัน — ทุกศาสตร์ยังอยู่ในหัวข้อ “ทุกคำทำนาย” |
| ภาษา | **คำทำนายภาษาไทย ภาษาอังกฤษ และภาษาจีนตัวย่อ** (คำทำนายภาษาอังกฤษเปิดแล้วทุกศาสตร์) หน้าเว็บสลับ TH / EN / 中文 |
| คอนเทนต์พร้อมโพสต์ | การ์ดแชร์ 1080×1350 สรุป 3 บรรทัด แผนปรับดวง 3 ข้อ |
| บัญชีสมาชิก (Google) | ⏳ เร็ว ๆ นี้ (ยังไม่เปิดระบบ) — บันทึกคำทำนาย ประวัติ พิมพ์/PDF ลบบัญชีเองได้ (`account.html`) |
| รายงานดวงฉบับยาว | `report.html` — รายงานพื้นฐาน (แปดอักษร + ทักษา + เลข 7 ตัว) รายงานดวงคู่ (12 นักษัตร + ธาตุเจ้าชะตา) รายงานรายปี (ภาพรวมปี + 12 เดือน) คำนวณในเครื่อง 3 ภาษา พิมพ์/บันทึกเป็น PDF · ตอนนี้เป็นตัวอย่างฟรี |

| โหมดไลฟ์/บูธ | โหมดคีออสก์ ล้างข้อมูลระหว่างผู้ใช้ |

## มาตรฐานเนื้อหา
- ทุกคำทำนายจบด้วยข้อความเตือนใจตามหลักกาลามสูตร: ใช้วิจารณญาณ ทุกอย่างเปลี่ยนได้ด้วยการกระทำ
- คำเตือนต้องนุ่มนวลและมีสิ่งที่ทำได้เสมอ ระบบตรวจถ้อยคำรุนแรงอัตโนมัติ
- มีกระบวนการให้เจ้าของภาษาไทย อังกฤษ และจีนตรวจคุณภาพเป็นรอบ ตามเกณฑ์ความเป็นธรรมชาติ ความนุ่มนวล ความถูกต้องตามตำรา และความปลอดภัย (`docs/FORTUNE-REVIEW.md`)
- ผู้อ่านกด “แจ้งปัญหาคำทำนายนี้” ได้ทุกคำทำนาย
- ไม่ขายเครื่องราง ไม่ชักชวนให้จ่ายเงินเพื่อแก้ดวง
- ใบหน้าและลายมือวิเคราะห์ในเครื่อง ไม่อัปโหลดภาพ
