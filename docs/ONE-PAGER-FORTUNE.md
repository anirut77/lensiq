# LENSIQ สำหรับครีเอเตอร์สายดูดวงและเพจคอนเทนต์ — 15 ศาสตร์ ไทย–จีน พร้อมการ์ดแชร์

**คำทำนายที่อ่านลื่น อ่อนโยน และอ้างอิงตำรา — เพื่อความบันเทิง ไม่ขู่ ไม่ฟันธง**

## สิ่งที่ได้
| | |
|---|---|
| 15 ศาสตร์ | โหงวเฮ้ง ลายมือ ดวงวันเดือนปีเกิด แปดอักษร ทักษา เลข 7 ตัว 9 ฐาน กราฟชีวิต ไพ่ทาโรต์ เซียมซี ฮวงจุ้ย เลขมงคล อี้จิง 12 นักษัตร ราศีตะวันตก ทำนายฝัน |
| ภาษา | คำทำนายภาษาไทยและภาษาจีนตัวย่อ หน้าเว็บสลับ TH / EN / 中文 |
| คอนเทนต์พร้อมโพสต์ | การ์ดแชร์ 1080×1350 สรุป 3 บรรทัด แผนปรับดวง 3 ข้อ |
| ผู้ช่วยเขียน (เลือกใช้) | Claude โดย Anthropic เรียบเรียงให้ลื่นขึ้น เฉพาะเมื่อผู้ใช้ยินยอม ส่งเฉพาะข้อเท็จจริงที่สกัดแล้ว |
| โหมดไลฟ์/บูธ | โหมดคีออสก์ ล้างข้อมูลระหว่างผู้ใช้ |

## มาตรฐานเนื้อหา
- ทุกคำทำนายจบด้วยข้อความเตือนใจตามหลักกาลามสูตร: ใช้วิจารณญาณ ทุกอย่างเปลี่ยนได้ด้วยการกระทำ
- คำเตือนต้องนุ่มนวลและมีสิ่งที่ทำได้เสมอ ระบบตรวจถ้อยคำรุนแรงอัตโนมัติ
- มีกระบวนการให้เจ้าของภาษาไทยและจีนตรวจคุณภาพเป็นรอบ ตามเกณฑ์ความเป็นธรรมชาติ ความนุ่มนวล ความถูกต้องตามตำรา และความปลอดภัย (`docs/FORTUNE-REVIEW.md`)
- ผู้อ่านกด “แจ้งปัญหาคำทำนายนี้” ได้ทุกคำทำนาย
- ไม่ขายเครื่องราง ไม่ชักชวนให้จ่ายเงินเพื่อแก้ดวง
