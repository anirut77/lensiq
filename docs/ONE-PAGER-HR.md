# LENSIQ สำหรับฝ่ายบุคคล — สัมภาษณ์อย่างมีโครงสร้าง ยุติธรรม และให้คนเป็นผู้ตัดสิน

**ชุดสัมภาษณ์ที่ช่วยให้กรรมการให้คะแนนอิสระบนเกณฑ์เดียวกัน — ระบบไม่ตัดสินใจจ้างงาน ไม่จัดอันดับผู้สมัคร**

## ปัญหาที่พบบ่อย
- กรรมการถามคนละแบบ ให้คะแนนจากความรู้สึก เปรียบเทียบผู้สมัครไม่ได้
- คำถามที่ไม่ควรถาม (ศาสนา สุขภาพ การตั้งครรภ์ สถานภาพสมรส) ยังหลุดในการสัมภาษณ์
- เครื่องมือ “AI สัมภาษณ์” ในตลาดอ่านอารมณ์หรือบุคลิกจากใบหน้า ซึ่งไม่มีหลักฐานทางวิทยาศาสตร์และเสี่ยงต่อการเลือกปฏิบัติ

## สิ่งที่ได้
| เครื่องมือ | ทำอะไร |
|---|---|
| ชุดสัมภาษณ์แบบมีโครงสร้าง | คลังคำถาม STAR ตามสมรรถนะ เกณฑ์คะแนน BARS 1–5 กรรมการให้คะแนนอิสระก่อนเห็นกัน สรุปความสอดคล้อง และรายการคำถามที่ไม่ควรถาม |
| โหมดฝึกซ้อม | ผู้สมัครหรือพนักงานฝึกตอบเอง ได้ข้อสังเกตการนำเสนอ (เห็นหน้า หันเข้ากล้อง จังหวะพูด) **สำหรับตัวเองเท่านั้น** |
| โหงวเฮ้งทีม | กิจกรรมละลายพฤติกรรม การ์ดบทบาทในทีม **เพื่อความบันเทิงเท่านั้น ห้ามใช้ประเมินคน** |
| เช็คชื่อด้วยใบหน้า | ลงชื่อเข้าอบรม/สัมมนา เฉพาะผู้ยินยอม มีทางเลือกใช้ชื่อหรือรหัส |

## หลักที่ฝังในเครื่องมือ
- **คนตัดสิน ระบบไม่ตัดสิน:** ไม่มีคะแนนรวมอัตโนมัติ ไม่มีการจัดอันดับ
- **ผู้สมัครมาก่อน:** ข้อสังเกตจากกล้องปิดเป็นค่าเริ่มต้น ผู้สมัครปฏิเสธได้และได้รูปแบบอื่น ผู้สัมภาษณ์เห็นได้เฉพาะเมื่อองค์กรยืนยัน DPIA และหลังส่งคะแนนครบแล้ว
- **ไม่เก็บข้อมูล:** อยู่ในแท็บเบราว์เซอร์ ปิดแล้วหาย ไม่มีภาพ เสียง หรือคำพูดถูกบันทึก
- ไม่วัดอารมณ์ การโกหก หรือบุคลิกภาพ

## เริ่มอย่างไร
ทดลอง 2 สัปดาห์ 5–15 การสัมภาษณ์ วัดความสอดคล้องของกรรมการ เวลาเขียนสรุป และความพึงพอใจของผู้สมัคร (`docs/PILOT-PLAN.md` ข้อ 3.4)
แพ็กเกจ: ฟรีสำหรับใช้งานบนเครื่อง · Business/องค์กร เมื่อต้องการอบรมกรรมการ แม่แบบ DPIA และ SLA (ราคาในใบเสนอราคา)
