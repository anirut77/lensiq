แดชบอร์ดผู้คุมสอบ

รวมเหตุการณ์จากหน้าผู้เข้าสอบและเครื่องกล้องในห้อง เป็นผังที่นั่งและรายการที่ควรไปดู ระบบแจ้งให้คนไปตรวจเท่านั้น ผู้คุมสอบเป็นผู้ตัดสินทุกกรณี ไม่มีภาพจากกล้องในหน้านี้

สัญญาณ “มากกว่าหนึ่งคน” เป็นตัวช่วยผู้คุมสอบ ไม่ใช่การตรวจจับที่ครบถ้วน: เมื่อมีคนที่สองในภาพ ระบบแจ้งได้ 28.8% (15 / 52) · n = 52 ภาพ · ที่มา: ชุดข้อมูลสาธารณะ (ภาพถ่ายสาธารณะจาก Open Images V7 ครึ่งที่ไม่ได้ใช้เลือกค่า ไม่ใช่ภาพห้องสอบจริง) · ในห้องสอบจริง: ยังไม่ได้วัด · ผู้คุมสอบต้องเดินตรวจตามปกติ

ห้องสอบ

นำเข้าไฟล์ / เชื่อมหลายเครื่อง

หน้าต่างในเบราว์เซอร์เดียวกันเชื่อมกันเองทันที สำหรับหลายเครื่องในห้อง ใช้ไฟล์นำเข้าด้านบน หรือเครื่องรวมข้อมูลในวง LAN (ตั้งค่า LENSIQ_EXAM_RELAY ดู docs/EXAM.md) ข้อมูลที่ส่งเป็นเหตุการณ์ JSON เท่านั้น
